## Sobre o Projeto

A **Calculadora de Consumo de Energia** é uma ferramenta desenvolvida em Python para estimar o consumo mensal de energia elétrica (em kWh) e o custo aproximado (em R$) de aparelhos eletrodomésticos.

O objetivo do sistema é auxiliar no monitoramento do uso de energia e na conscientização sobre gastos elétricos residenciais.

---

## Fórmulas Utilizadas

O programa realiza os cálculos utilizando duas fórmulas principais:

1. **Consumo Mensal de Energia (kWh):**
   $$\text{Consumo (kWh)} = \frac{\text{Potência (W)} \times \text{Horas por dia} \times 30 \text{ dias}}{1000}$$

2. **Custo Mensal Estimado (R$):**
**Custo (R$) = Consumo (kWh) × Valor da Tarifa (R$/kWh)**

> *Nota: O sistema utiliza como padrão uma tarifa fixa de **R$ 0,90 por kWh**.*
